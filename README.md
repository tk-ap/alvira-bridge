# ALVIRA Bridge

ALVIRA Bridge is the sister product/site to ALVIRA. It carries an ALVIRA profile into the AI tools a person uses.

## Current source status

This repository is being initialized from the currently deployed Bridge experience at `https://alviratech-bridge.vercel.app/` while the original CTO.new project export is unavailable.

The initial app source is therefore a **reconstruction of the publicly rendered site**, based on its visible content and structure. It is not represented as the original CTO.new source.

The current deployment was observed to communicate:

- One profile across every agent.
- The distribution problem created by duplicated AI context.
- Guides for ChatGPT, Claude, Gemini, Cursor, and generic Markdown-based tools.
- A single ALVIRA profile as the source of truth.

## Product direction

See `AGENTS.md` for the owner-approved ALVIRA ↔ Bridge brand architecture. In particular:

- ALVIRA = Context Engine.
- Bridge = Context Distribution.
- ALVIRA: “Build the context your AI is missing.”
- Bridge: “Take that context everywhere.”
